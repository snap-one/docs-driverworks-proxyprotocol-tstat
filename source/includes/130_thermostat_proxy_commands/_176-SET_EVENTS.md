## SET_EVENTS

Used in conjunction with Preset Scheduling. This command is sent to the protocol driver for updating all of the preset events. 

### Name

`SET_EVENTS ()`




| Parameter | Type   | Description                                       |
| --------- | ------ | ------------------------------------------------- |
| XML       | STRING | XML of all of the current preset scheduler events |

### Command Sent to Protocol Driver

`SET_EVENTS`


### Notification

No notifications returned with this command.
